# ZuLink PDT v1.0.0 | Official Release

Platform Detector Terminal
USB Device Intelligence & Hardware Diagnostics for GSM Technicians

# Developed by ZuLink Unlocker

ZuLink PDT is a Windows diagnostic utility designed to help GSM technicians inspect connected mobile devices, identify USB hardware, monitor connection states, and analyze available device information.

Whether you're troubleshooting an undetected phone, investigating USB connection instability, or checking device interfaces before servicing, ZuLink PDT provides a centralized view of the information exposed by Windows.

# Key Features

- USB Device Identification: Inspect connected devices and available identifiers.
- Hardware ID & Port Mapping: View USB hardware IDs, device interfaces, and available port information.
- Connection-Mode Detection: Identify supported device states based on available USB and system information.
- Device Profiling: Organize detected device information into readable profiles.
- Driver & Protocol Information: Display relevant information when exposed by Windows or supported detection methods.
- Live Diagnostic Logs: Monitor detection events and investigate connection issues.
- Copyable Device Profiles: Copy diagnostic information for troubleshooting and technical support.

# Built for Real-World GSM Diagnostics

ZuLink PDT helps technicians investigate common connection problems, including:

- Phones that are not detected correctly by Windows.
- Missing, incorrect, or conflicting device drivers.
- Unexpected USB disconnections and reconnection loops.
- Hardware identification and port-mapping issues.
- Unclear device connection states during servicing.

# Device & Platform Coverage

ZuLink PDT is designed for use in mobile servicing environments involving Android smartphones, Apple devices, and feature phones.

Detection capabilities depend on the device, connection mode, installed drivers, Windows configuration, and the information exposed by each interface. Exact chipset identification, security-state extraction, and low-level protocol support should be considered supported only where verified by actual implementation and testing.

# Requirements & Usage

1. Operating system: A compatible Windows PC.
2. Drivers: Install the appropriate device drivers for the phones and connection modes you intend to diagnose.
3. Permissions: Run as administrator only when a specific diagnostic function requires elevated privileges.
4. Connection: Use a reliable USB cable and a suitable USB port.
5. Diagnostics: Connect the device and inspect the detected information and diagnostic logs.

# Technical Disclaimer

ZuLink PDT is a diagnostic and device-identification utility. Device detection does not guarantee successful ADB communication, Fastboot access, EDL entry, BROM communication, DFU access, firmware compatibility, or successful hardware interrogation.

The application does not natively flash firmware or modify device partitions unless such functionality is explicitly implemented in a future release.
